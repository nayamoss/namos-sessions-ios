# Product

## Register

product

## Users

Event organizers and assigned reviewers using a mobile companion while managing an event. They need to review submissions, make decisions, and complete operational work quickly with limited time and attention.

## Product Purpose

Namos Sessions provides an authenticated, event-scoped workflow companion to the Namos web application. It makes the essential, on-the-go event-management actions practical without creating a separate backend or workflow.

## Brand Personality

Calm, practical, accessible. The interface supports focused work and stays quiet around operational information.

## Anti-references

Decorative dashboard tropes, visual noise, novelty controls, and interfaces that make time-sensitive event work feel complicated.

## Design Principles

- Put the current workflow before product decoration.
- Keep event context and permission boundaries clear.
- Use familiar mobile patterns that work under time pressure.
- Reveal detail progressively, while keeping important actions easy to reach.
- Treat accessibility as a baseline, not an enhancement.

## Accessibility & Inclusion

Use clear labels, system Dynamic Type-compatible controls, sufficient color contrast, and information that does not rely on color alone. Avoid nonessential animation.
